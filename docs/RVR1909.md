# Edición Minelly RVR1909

Esta edición especial está pensada para compartir una app que ya trae:

- **Reina-Valera 1909**.
- **Interlineal hebreo/griego** completo: tokens, Strong, morfología y
  transliteración, con el léxico STEPBible como apoyo.
- Los datos necesarios para el panel de interlineal.

No incluye NTV, RVR1960, RVA2015, LBLA, comentarios editoriales, diccionarios
editoriales ni libros de terceros.

## Instaladores

Se generan con el workflow manual
`.github/workflows/package-rvr1909.yml` y se publican como release aparte.

- **Fedora 44:** `Minelly RVR1909-0.2.0-1.x86_64.rpm`
- **Ubuntu 24.04+:** `Minelly-RVR1909-0.2.0-amd64.deb` y `.AppImage`.
- **Windows 11 x64:** instalador NSIS.

## Instalar en Ubuntu 24.04+

```bash
sudo apt install ./Minelly-RVR1909-0.2.0-amd64.deb
```

O usa el AppImage sin instalar:

```bash
chmod +x Minelly-RVR1909-0.2.0-amd64.AppImage
./Minelly-RVR1909-0.2.0-amd64.AppImage
```

Ubuntu 22.04 no incluye WebKitGTK 4.1 en sus repositorios estándar; por eso el
paquete se compila para Ubuntu 24.04 o posterior.

## Por qué un identificador distinto

La edición usa `com.minelly.rvr1909`, no `com.teoamoxtli.desktop`. Así no hereda
la biblioteca de una instalación anterior y no aparece contenido que el usuario
hubiera importado antes.

## Datos y derechos

La RVR1909 se considera de dominio público en muchas jurisdicciones, pero el
régimen no es idéntico en todos los países. El interlineal usa STEPBible
TAGNT/TAHOT (CC BY 4.0), Strong's Greek (CC0), Tischendorf (dominio público),
STEPBible Lexicon (CC BY 4.0) y anotaciones BHS/ETCBC (CC BY), con el texto BHS
© Deutsche Bibelgesellschaft. Strong-PLUS no se incluye por su licencia
CC BY-NC-ND.

Antes de distribuir esta edición, revisa [`docs/DATA.md`](DATA.md) y el archivo
`src-tauri/resources/rvr1909/LICENSES.md`. Conserva las atribuciones en la
release.

## Compilar

```bash
npm ci
npm run tauri build -- --config src-tauri/tauri.rvr1909.json --bundles rpm
```

En Windows:

```powershell
npm ci
npm run tauri build -- --config src-tauri/tauri.rvr1909.json --bundles nsis
```

## Verificar

El instalador no debe contener NTV, RVR1960, MacArthur ni otros recursos. Para
comprobarlo, instala en una máquina limpia o borra/renombra la carpeta de datos
`com.minelly.rvr1909` antes de abrir.
