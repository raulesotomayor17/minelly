# Código de Conducta

## Nuestro compromiso

En Minelly queremos una comunidad acogedora, paciente y respetuosa. Nos
comprometemos a que la participación no dependa de la edad, el cuerpo, la
discapacidad, la etnia, el nivel de experiencia, la identidad de género, la
orientación sexual, la religión (o su ausencia), la nacionalidad o el nivel
socioeconómico.

Este es un proyecto de estudio bíblico, pero no es un espacio para imponer una
interpretación, una confesión o una postura política. Se puede debatir con
respeto; no se puede acosar.

## Comportamiento esperado

- Usa un lenguaje claro, amable y profesional.
- Escucha y da por buena la intención de quien pregunta.
- Critica ideas y código, no personas.
- Reconoce el trabajo ajeno y atribuye las fuentes.
- Acepta que quien mantiene el proyecto pida cambios o rechace propuestas.
- Respeta la privacidad: no publiques datos personales, rutas locales, claves de
  API ni módulos con derechos de autor.

## Comportamiento inaceptable

- Acoso, insultos, amenazas o comentarios discriminatorios.
- Atención sexual no solicitada.
- Publicar información privada de otra persona sin permiso.
- *Trolling*, interrupciones deliberadas o descalificaciones repetidas.
- Compartir material pirateado, módulos con DRM eludido o contenido que vulnere
  derechos de autor.
- Suplantar a otra persona o afirmar falsamente una afiliación con Minelly.

## Alcance

Este código se aplica a los *issues*, *pull requests*, discusiones, revisiones
de código y cualquier espacio del proyecto. También se aplica cuando alguien
representa a Minelly en otro espacio.

## Cómo reportar

Si sufres o presencias una conducta inaceptable:

- Si no es urgente y no expone datos privados, abre un *issue* indicando solo lo
  necesario para entender el problema.
- Si es sensible, contacta al mantenedor a través de su perfil de GitHub
  ([@raulesotomayor17](https://github.com/raulesotomayor17)) o usa el canal
  privado de [`SECURITY.md`](SECURITY.md) si hay riesgo para una persona.

No se exige que la persona afectada se enfrente públicamente a quien la acosó.
Las denuncias se tratarán con la discreción posible.

## Consecuencias

Quien mantiene el proyecto puede:

1. Pedir una corrección o una disculpa.
2. Eliminar comentarios, *issues* o *pull requests*.
3. Suspender temporalmente la participación.
4. Expulsar de forma permanente del proyecto.

La medida será proporcional a la gravedad y a la reiteración. Las decisiones se
documentarán de forma privada cuando sea necesario proteger a las personas.

## Atribución

Este código está inspirado en el [Contributor Covenant](https://www.contributor-covenant.org/)
y en las normas habituales de proyectos de software libre. Se distribuye bajo
los mismos términos que la documentación del proyecto.
